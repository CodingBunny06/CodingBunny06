## 🚀 Featured projects

### [FiberLab](https://github.com/CodingBunny06/FiberLab)

An interactive optical-fiber and physics simulation laboratory built with Python and Streamlit.

- Interactive modules for fiber optics, signal propagation, attenuation, and matter waves
- Scientific computing and visualisation with NumPy, SciPy, Plotly, and Matplotlib
- Automated tests and GitHub Actions CI

**[Open the live app](https://fiberlab-xjlvqbfj8kskptzbwddwwc.streamlit.app/)**

### [Gradient Explorer](https://github.com/CodingBunny06/Gradient-Explorer)

An interactive mathematical visualisation project exploring gradients and steepest ascent.

- Streamlit interface for experimenting with mathematical functions
- Equation validation with SymPy
- Automated tests with pytest
